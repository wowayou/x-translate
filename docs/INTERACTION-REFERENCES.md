# 0.2 交互参考与实施范围

参考的是公开描述的产品行为，所有代码与图标独立实现。本轮没有 fork、复制其他项目源码或使用它们的品牌素材。

| 参考 | 公开描述的行为 | XTranslate 的采用方式 |
| --- | --- | --- |
| [QTranslate 官方项目](https://github.com/ahatem/QTranslate)与[发布说明](https://github.com/ahatem/QTranslate/releases) | 选中文字后快捷键弹窗、键盘驱动、复制译文、清空输入、运行中取消、界面语言 | 保留快捷键闭环；加入明确粘贴/清空、聚焦原文/复制译文快捷键；翻译主按钮在请求中用于取消；简体中文与英文 UI 可独立切换 |
| [Pot 官方翻译设置](https://pot-app.com/docs/config/translate.html) | 跟随鼠标、记住目标语言、失焦关闭、置顶时不因失焦关闭 | 区分临时取词弹窗与手动打开的窗口；仅临时弹窗可失焦收起；固定按钮避免读译文时意外消失；目标语言与软件界面语言保持独立 |
| [STranslate 官方介绍](https://stranslate.zggsong.com/) | Windows 即用即走的划词与快捷键交互、设置入口 | 维持常驻托盘和紧凑单窗口；原有 Win32/UI Automation 路径继续使用，不复制其功能平台或插件系统 |

## 具体边界

- 软件语言：跟随系统 / 简体中文 / English。只改变界面标签、状态、错误、设置和托盘菜单，不更改原文、译文、目标语言或翻译服务，不触发新请求。
- 临时弹窗：从快捷键取词进入；失焦收起由设置控制，固定时保持可见；进入设置窗口或使用下拉选择时不能误收起。
- 手动窗口：从应用启动或托盘进入，失焦仍保持窗口。
- 翻译中：明确显示请求状态；取消不会改用别的服务，迟到结果不能覆盖新的输入或重新弹出窗口。
- 本轮不增加输入即自动发送、自动复制或自动替换原文，避免额外网络请求与剪贴板写入。

## 验收要求

双语标签键集合完整；语言保存与重启生效；中英文主窗/设置截图；无原文时不可翻译；清空使旧请求失效；复制与聚焦快捷键；固定/失焦/设置弹窗边界；保留原有取消、来源与数据保护测试。

性能测量使用固定测试文本和模拟翻译，不调用付费 API、不读取用户剪贴板；资源数据与本地 UI 周期延迟单独报告，网络耗时不得混为 UI 性能。
