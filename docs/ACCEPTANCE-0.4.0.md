# 0.4.0 发布验收

状态：**验收中，尚未发布**。正式下载状态以 [GitHub Releases](https://github.com/wowayou/x-translate/releases) 为准；不覆盖 0.3.0 的标签或附件。

## 验收约束

- 保留原有 Core、Diagnostics、流式／取消／回退／密钥隔离测试，不以新界面为由放宽旧断言。
- 基线从 `v0.3.0`（`bf49f40`）导出，用与候选相同的 .NET 10.0.401 SDK / 10.0.12 运行时构建。发布包使用默认软件渲染；便携与轻量分别比较，预热与正式轮次分别记录。每组至少三轮，测试进程不并行竞争。
- 使用本地固定数据和模拟 HTTP；不读取用户配置、正文或剪贴板，不调用付费接口，不改系统显示／主题设置，不停止用户进程。
- 真实跨屏、降级资源合约、离屏缩放截图分别记录，不能互相冒充。Win10、ARM64、远程桌面和系统高对比度切换若没有实测，明确留在未覆盖范围。
- 便携／轻量最终包各自通过功能检查；验证真实 0.3.0 包升级到候选，及候选未来升级／回滚边界。包中不得包含用户／测试数据。
- 短测不替代八小时长测；任何未完成的发布阻塞项不得称为已通过。

## 当前证据与发现

原始证据根目录：`artifacts/verification/release-0.4.0-20261014/`。

- 初始候选：Core 68/68、Diagnostics 10/10；三轮交替基准完成。旧探针中的约 92 ms 本地译文刷新 p95 未再复现；启动／离屏 Show-Hide 仍有波动，需要以最终发布包对照为准。
- 新增真实跨屏测试首次失败：125% 屏幕的最大尺寸误用先前 150% 的 DPI，实际最大值 1280×680，而工作区应为 1536×816。修复 `WindowPlacement`：在 WPF 完成 DPI 转换后合并处理尺寸限制。
- 修复后 `compatibility-3-smoke/run-20261014-112506-c8a8fdcf/ui-smoke.json` 62/62：主窗、设置窗在 125%／150% 两块屏幕往返，包含负坐标副屏；原生 DPI、WPF DPI、最大尺寸与物理工作区一致。
- 同次通过：锁定设置文件时旧配置不变、保存错误可见、取消恢复主题、托盘启停保存失败回滚；主窗隐藏时实际托盘菜单可获得键盘焦点，并在另一个受控窗口激活时收起。
- 本机：Windows 11 25H2 build 26200 x64、20 逻辑处理器、非远程会话。原生工作区：1920×1020 @ 120 DPI；2160×1548 @ 144 DPI，副屏原点 (-2160, -194)。

## 明确未覆盖

- Windows 10 LTSC、ARM64 仿真、远程桌面：没有对应实际环境。
- 系统高对比度开关与任意用户配色：有资源／对比度检查，未改变用户 OS 设置来做端到端切换；不等于完整可访问性验收。
- 100%／200% 是 WPF 渲染检查，物理跨屏实测仅覆盖当前的 125%／150%。
- 真实付费 AI 网络调用、所有第三方应用的取词与剪贴板管理器组合不在本地自动验收范围；原生协议合约与请求生命周期使用固定 mock 测试。
- 无代码签名；SHA-256 用于发布包完整性校验，不等于发布者身份认证。Windows SmartScreen 可能提示未知发布者。
