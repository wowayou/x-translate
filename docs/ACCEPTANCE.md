1. Release 构建：零警告、零错误。
2. 核心测试：12/12，通过模拟 HTTP 验证三个适配器、来源、错误、取消、无 fallback、设置快照及异常响应。
3. 发布 EXE 启动并创建真实 WPF 窗口。
4. Win32 全局快捷键注册及释放。
5. 对明确指定的本程序 WPF 测试控件读取真实 UI Automation 选区。
6. 弹窗位于当前显示器工作区内。
7. 连续请求时旧结果不会覆盖新结果；修改原文会清除旧译文。
8. 收起弹窗后请求被取消，迟到结果不重新打开窗口。
9. HTTP 失败保留当前服务，不自动切换。
10. 超过 3000 字符的原文被 UI 拦截。
11. DPAPI 密钥加密与读取往返成功，配置文件不包含测试密钥明文。

## 已发现并修复

- 取词过程中切换窗口：只要剪贴板仍由目标进程更新，先恢复原剪贴板，再终止取词。
- 取词过程中退出：取消请求，保持 Dispatcher 运行并等待取词清理，最多 3 秒，再退出。
- 剪贴板恢复部分失败：按格式重试并继续恢复其余格式；错误提示明确说明可能未恢复，不能声称未覆盖。
- 剪贴板延迟渲染：读取内容后再记录序列号，避免将本次渲染产生的序列变化误判为用户的新复制。
- 译文解析不能静默丢弃异常片段；兼容 AI 服务显示实际接口主机与返回模型。

## 未完成的验收，不视为通过

- 后台测试窗口被 Windows 拒绝获取前台焦点，所以自动化验证使用明确指定的测试控件；完整的“外部应用选中 → 实际按快捷键 → 弹窗”链路仍需手动验收。
- 模拟复制路径未在用户剪贴板上执行自动化破坏性测试；与剪贴板管理器、系统剪贴板历史、慢响应应用的组合仍有风险。
- DeepL 和 OpenAI 兼容 API 没有使用真实付费凭据调用，只完成请求/响应契约测试。
- 没有完成混合 DPI、多显示器排列、Windows 10、管理员应用、所有浏览器/办公/聊天应用矩阵。
- 没有完成 8 小时稳定性或空闲内存测试。验收 JSON 的工作集包含测试、网络与截图开销，不能用于宣称轻量或达到 <60 MB。
- 首版未实现 OCR、比较、Quality Guard、历史和开机启动。

## 建议手工验收顺序

1. 粘贴一段英文并翻译，确认网络、来源、复制译文。
2. 分别在记事本、浏览器和最常用办公软件中选中文本，按界面显示的快捷键取词。
3. 原剪贴板放一段测试文本，取词后在记事本粘贴，检查原内容是否恢复；只用可丢弃的测试数据执行。
4. 在设置中开启自动翻译，再重复第二步；测试 Esc、连续取词、网络错误和托盘退出。
5. 在不同缩放显示器间移动窗口，并在屏幕边缘触发取词。
