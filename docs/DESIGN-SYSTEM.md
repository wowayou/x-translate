# 设计与交互规范（0.4.0）

本文件是视觉与交互规范的入口。实现位于 `src/XTranslate.App/UiStyles.xaml`，由 `UiAppearance` 在加载所选主题后初始化，避免启动时先加载完整系统主题再加载保存的深／浅色主题。基于 .NET 10 自带的 `PresentationFramework.Fluent` 资源字典，不引入第三方 UI 包、不复制其它翻译器源码或素材。QTranslate 提供紧凑工具交互参考；Xbox Game Bar 提供卡片层次、功能性强调色与置顶状态的参考，而不是要求复制硬件看板。

## 外观与材质

- `UiAppearance` 管理独立于界面语言、翻译语言的 `System / Light / Dark` 偏好。只切换资源字典，不重建窗口、清空文本或重发请求。
- 系统强调色与高对比度由运行时主题处理。主题在设置中即时预览，取消恢复、保存持久化；旧版配置缺少外观字段时默认为跟随系统。
- Windows 11 22H2 及以上可使用系统 Mica（云母）背景。它不是全透明 Acrylic（亚克力）悬浮层；不支持的系统、远程会话或运行时关闭材质时使用实色。背景材质不构成使用前提。
- 保留原生标题栏、系统菜单、缩放、最大化和 Snap 贴靠。不使用 `AllowsTransparency`、点击穿透、强制硬件渲染、联网图片或自制动画计时器。
- 默认软件渲染不变；材质由 Windows 合成，不以加载显卡驱动或放宽旧测试换取视觉效果。

## 语义资源与样式

颜色由运行时主题决定，不再使用 0.3.0 的固定 `Ink / Accent / Canvas` 色值表，也不在窗口 XAML 中写死颜色。

| 资源／样式 | 用途 |
| --- | --- |
| `WindowBackground / WindowForeground` | 实色降级窗口背景与正文 |
| `TextFillColorPrimaryBrush / TextFillColorSecondaryBrush` | 正文／说明、来源、状态与页脚 |
| `CardBackgroundFillColorDefaultBrush / CardStrokeColorDefaultBrush` | 卡片填充与克制的轮廓 |
| `AccentFillColorDefaultBrush` | 主操作、选中导航、输入焦点 |
| `SystemFillColorCriticalBrush` | 错误提示 |
| `SystemFillColorAttentionBackgroundBrush` | 更新通知条 |
| `Card / SectionTitle / FieldHelp` | 卡片、分区标题、帮助文字 |
| `PrimaryAction / IconAction / IconToggle` | 主操作、带可访问名称的图标操作、置顶切换 |
| `TranslationEditor / TranslationOutputStyle` | 原文编辑、可选取的只读纯文本译文 |
| `NavTab` | 设置左侧导航，选中标记不改变整页字重 |

主操作与已选中置顶图标的前景由 `AccentForegroundConverter` 根据背景选择黑／白文字，避免用户设置亮黄、青色等强调色后白字不可读；高对比度使用系统高亮文字。主按钮悬停不切成不匹配的白字。测试检查浅／深色正文和操作文字至少 4.5:1 的对比度；这不是完整的读屏、系统高对比度切换或真人可访问性验收。

字体：Microsoft YaHei UI；图标使用系统 Segoe Fluent Icons / Segoe MDL2 Assets。主标题 18、设置标题 22、分区标题／正文编辑 16、默认正文 13、帮助 12、次要信息 11。卡片圆角 8，按钮约 5；尺寸均为 WPF 设备无关单位。

## 布局与缩放

- 主窗默认 620×660，最小 480×520；原文／译文为主，服务与目标语言在上方，操作与发送目的地说明在两者之间。空间不足时整个内容可滚动。加入会话级学习检查开关与未检查提示后，普通内容区最小高度为 660；学习模式内容区最小高度为 960、原文区高 140，检查详情可独立滚动／折叠，避免挤掉译文。这些是可滚动内容尺寸，不增加窗口最小尺寸。
- 设置默认 800×680，最小 640×480；左侧五个分区，右侧独立滚动内容，保存／取消保持在窗口底部。
- `WindowPlacement` 按当前显示器的实际工作区与 DPI（Dots Per Inch，系统缩放的基础单位）换算最大尺寸，小屏时可降低窗口最小尺寸。跨屏事件合并到 WPF 完成缩放转换之后再计算，不能在 `DpiChanged` 回调中沿用旧原生 DPI。
- 100%／150%／200% 的离屏渲染图是布局证据，不替代真实显示器切换。原生跨屏范围与测试结果以本版验收记录为准。

## 交互保证

- **一个明确的下一步**：配置类错误显示「打开设置」，定位出错服务／字段；临时错误显示「重试」，只发一次请求。错误信息不含密钥或远端正文。
- **发送前说明**：未配置密钥的服务有标记；翻译按钮旁始终写明原文的接收主机（开启回退时包含备用顺序）。主题变化不改变接收方。
- **未完成内容不冒充结果**：流式预览标记「尚未完成」，失败／换服务前清除；整份复制只在成功后启用。译文以纯文本 Run 更新，不解析 HTML、XAML 或 RTF；追加保持已有选区，兼顾从右到左文字和辅助技术的文本读取。
- **切换不破坏工作**：语言或主题切换保留原文、选区、译文、服务、目标语言与当前请求代次。取消设置恢复预览；保存失败保留旧配置并显示错误，不能假装已保存。
- **检查不替原文遮错**：会话级学习开关默认关闭；开启后手动执行「检查并翻译」，原文不改写，观察／建议、最小修正、理解依据和译文分开。只使用所选 AI，一次请求、不自动回退或显示半份检查；意思不确定先澄清，不启用整份译文复制。普通翻译明确标注原文未检查，详细合约见 [语言学习计划](LEARNING-PLAN.md)。
- **置顶是状态切换**：Toggle 自动化模式、勾选状态、`Topmost` 和可访问名称一致。只置顶，不穿透鼠标。
- **托盘**：打开、启停取词快捷键、设置、关于与更新、退出；与窗口共享主题。主窗隐藏时也可打开菜单；Escape 或切换到其它窗口只收起菜单。
- **快捷键**：Ctrl+Enter 翻译／取消，Ctrl+L 聚焦原文，Ctrl+Shift+C 复制译文，Esc 收起。停用全局取词快捷键会释放注册；新组合冲突时保留原注册。托盘启停保存失败时恢复旧状态。
- **设置分区**：通用／翻译服务／失败时换服务／隐私与数据／关于与更新；校验失败定位问题分区并聚焦字段。
- **通知**：更新通知条非模态；文字、输入框和图标保留可访问名称／标签，状态通知使用 `LiveSetting=Polite`。系统原生窗口操作保持可用。

## 验证入口

`verify.ps1 -NativeChecks` 覆盖核心策略、真实 WPF 生命周期与本地原生边界，输出中英文、深浅色、流式、设置、托盘及最小尺寸截图。新增跨屏检查只移动本次测试窗口，不改变系统缩放或读取其它应用。人工查看截图仍是必要步骤。
