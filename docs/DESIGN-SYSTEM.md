## 交互模式

- **一次只给一个下一步**：状态栏右侧的 `StatusAction` 按钮。配置类错误（缺密钥、无权限、路径或模型不存在、协议不符、不支持流式）显示「打开设置」，直接打开对应设置页并选中出错的服务；临时错误（超时、网络、限流、服务端、回答不完整）显示「重试」，只发一次请求。其他状态不显示按钮。
- **事前说明而非事后报错**：未设置密钥的服务在下拉中标「未设置密钥」；选中时状态栏说明并给出「打开设置」，仍允许选择。翻译按钮旁始终写明原文会发送到哪些主机（含备用服务顺序）。
- **非模态通知条** `InfoBar`：只用于「有新版本」「更新已就绪需重启」这类可稍后处理的事，带一个操作和关闭按钮；不弹窗打断。
- **设置分区**：通用 / 翻译服务 / 失败时换服务 / 隐私与数据 / 关于与更新。保存时的校验错误会切换到包含问题字段的分区并聚焦该字段（`SettingsWindow.Reveal`）。取消不改任何已保存配置。
- **未完成内容不冒充结果**：流式预览标记「尚未完成」，失败或换服务前清除；整份复制只在完成后可用。
- **界面语言切换**只改文字，不重发请求、不清空内容；状态参数在渲染时本地化。
- 所有可操作控件有 `AutomationId`；输入框用 `LabeledBy` 关联标签；状态、更新状态、通知条为 `LiveSetting=Polite`。键盘：Ctrl+Enter 翻译、Ctrl+L 原文、Ctrl+Shift+C 复制、Esc 收起；设置导航支持 Ctrl+Tab 与方向键。

## 验收

`verify.ps1` 的 WPF 验收覆盖上述模式，并输出中英文主窗、设置、AI 服务、流式、回退、关于页与通知条截图（`artifacts/verification/<版本>/run-*/`）。改动界面后需要查看截图，而不只看测试是否通过。
